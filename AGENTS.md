Dieses Projekt soll eine Reimplementierung der alten Windowsanwendung
NuclearReactor_1_2.exe (mutmaßlich Delphi)
als browserbasierte komplett clientseitige Anwendung werden.
Die Funktionalität der Anwendung soll durch automatische Tests abgesichert werden.
NucReact_1_1.jpg zeigt die etwas ältere 1.1 mit ein paar Erklärungen.

Die Entwicklung läuft auf debian 13. Wenn du tools brauchst z.B. für die Analyse
bevorzuge solche die in den nativen Debian Paketquellen verfügbar sind - bitte den Benutzer
sie zu installieren, installiere nie selbst neue Software.
Du darfst zur Analyse temporäre python skripte erstellen.
